Peyrassol / Design system

Design system

Les règles visuelles du site, relevées dans les maquettes Figma desktop (1440 px). Chaque valeur est une variable CSS définie dans assets/css/style.css. Les tailles mobiles (≤ 767 px) sont notre adaptation : il n’existe pas de maquette mobile.

Les valeurs affichées sont lues en direct dans le CSS : passez en aperçu « Mobile » pour voir l’échelle mobile.

Espacements

Marges, écarts entre cartes et hauteurs de section reprennent cette échelle. Gouttière latérale : --gutter (24 px, 20 px en mobile). Largeur de contenu : --container (1200 px).
